# CHAMELEON BG

Существующая PWA для изучения болгарского на русском, с профессиональной железнодорожной практикой. Текущая версия 0.3 сохраняет прежнюю компоновку и пользовательский прогресс.

## Запуск

```sh
npm install
npm run dev
```

Адрес по умолчанию: http://localhost:5173. В этом рабочем каталоге уже подготовлены `.venv/` и болгарская модель Piper в `data/voices/`. Vite автоматически запускает локальный TTS или использует уже работающий процесс. Установка системных голосов не требуется.

```sh
npm run build
npm run preview
```

`dist/` — статическая PWA. Готовые MP3 работают и при статическом размещении. Для генерации новых фраз в размещённой версии нужен доступный `/api/tts`, совместимый с локальным сервером; системный голос bg-BG остаётся последним резервом. Сам по себе статический хостинг Python не запускает.

## Реальное содержимое

- 16 658 словарных записей; 1 395 из них имеют не менее пяти контекстов с переводом и выделены в активный словарь.
- 17 819 уникальных болгарско-русских контекстов: прямые пары Tatoeba, связки через общее предложение, 417 из русского Викисловаря, 200 авторских профессиональных реплик, FLORES-200.
- 437 глагольных парадигм, включая возвратные глаголы, девять времён, лица/числа, род, утверждения/отрицания/вопросы, сравнение и практика.
- 44 грамматические темы и **1 029** качественных упражнений (выбор, подстановка, порядок слов, исправление ошибок, перевод RU→BG, времена, артикли, клитики).
- **409** полноценных диалогов / 1 742 реплики с озвучиванием, точными переводами и контрольными вопросами.
- **525** интерактивных упражнений в Тренажёре аудирования (фразы, числа, время, цены, платформы, вокзальные объявления, радиопереговоры BDZ/NRIC, монологи) с контролем скорости (0.75x–1.1x).
- **305** разговорных ситуаций в Голосовом режиме по 12 ключевым темам (магазин, транспорт, работа, жильё, врач, документы, кафе, собеседование, руководство, депо, обслуживание локомотивов, отказы и безопасность) с поддержкой Web Speech API, текстовым режимом и пословным сравнением.
- **2 082** технических термина Railway Academy и 220 проверенных контекстных примеров.
- 596 проверенных фотографий с источниками и лицензиями (Wikidata/Commons).
- 48 653+ синтезированных аудиофайла Piper (100% покрытие учебных текстов).
- 25 механик заданий, алгоритм FSRS по двум навыкам, адаптивный маршрут обучения.

## Интерфейс и звук

GSAP и Motion: многослойная Aurora, параллакс, динамическая подсветка, стеклянные панели, световые волны на кнопках, 3D-карточки, пространственные переходы, анимации результата и реактивная болгарская клавиатура. Поддерживаются системное и пользовательское ограничение движения.

Единый проигрыватель ищет нормализованный текст в индексе MP3, затем обращается к локальному серверу и только затем к настоящему голосу bg-BG. Скорость, громкость, ограниченная нормализация по RMS, компрессор, остановка очереди и повтор доступны в общем плеере. Спектр читается из реального Web Audio; для системного TTS сигнал браузером не раскрывается.

## Проверки и сборка данных

```sh
npm test
npm run content:check
npx tsx scripts/check-exercises.ts
npm run build
```

Для воспроизводимого импорта нужны исходные дампы в `data/sources/`:

```sh
npm run content:fetch
npm run content:build
npm run audio:texts
npm run audio:generate
```

`scripts/import-engineering-labels.py` использует явный список допущенных понятий Wikidata. `scripts/expand-photos.py` сохраняет происхождение Commons, а `data/photo-review/excluded.json` исключает отклонённые подборки. Оптимизация изображений: `python scripts/optimize-photos.py`.

Подробности, лицензии, проверки и оставшиеся ограничения: [docs/DEVELOPMENT-REPORT.md](docs/DEVELOPMENT-REPORT.md). Количество материалов не является сертификатом полноты курса A1–C2.


### Проверка производительности

Изменения и ограничения измерений: [отчёт от 16 октября 2026](docs/performance-audit-2026-10-16.md).
`npm run performance:bench -- after` записывает измерения Node и размеры production-сборки;
`npx tsx scripts/check-performance-build.ts` проверяет начальный граф и Service Worker.
Для реальных кадров, длительных задач и Event Timing откройте «Настройки → Плавность на этом устройстве» и скачайте профиль.
React Profiler включается сборкой `npm run build:profile`; обычная production-сборка сохраняет стандартный React без накладных расходов профилировщика.
