# Результат доработки CHAMELEON BG

Изменения сделаны в существующем приложении. Схема базы прогресса остаётся версией 2, идентификаторы слов и прежние FSRS-карточки сохранены. Новые списки сложных слов и ошибочных заданий — необязательные поля профиля; старые резервные копии поддерживаются.

## Интерфейс

Общая система взаимодействий использует GSAP и Motion. Три световых плана Aurora реагируют на курсор и прокрутку с разной глубиной. Панели имеют композицию градиентов, внутреннего света, краёв и размытия. Кнопки дают световую волну; карточки и фотографии — управляемый наклон. Карточки переворачиваются на 180° с двумя поверхностями и скрытой оборотной стороной; невидимая сторона исключена из клавиатурного фокуса. Навигация использует пространственный переход. Добавлены болгарская экранная клавиатура, импульсы клавиш, эффекты правильного/ошибочного ответа и завершения урока.

Настройка reduced motion и системное предпочтение отключают движение. На телефонах используются два более лёгких световых слоя и отсутствует отслеживание курсора. Анимации фона приостанавливаются при скрытии вкладки; визуализатор работает только при воспроизведении. Three.js не добавлен: используемый 3D-переворот реализован CSS perspective без постоянного WebGL-рендеринга.

## Единое аудио

Все экраны используют `src/speech.ts`, включая ранее обособленный голосовой тренажёр. Индекс связывает нормализованный текст с подготовленными MP3; обработаны пробелы, регистр и учебные ударения, сохранено различие й/и и ѝ/и. Порядок: готовый файл → сервер Piper → реальный голос bg-BG → понятное сообщение о недоступности. Русские и английские голоса автоматически не подставляются.

Есть состояние загрузки, обработка ошибок, повтор, регулировка скорости и громкости, отсутствие перекрытия очередей, ограниченная нормализация усиления по RMS и компрессор. Спектр берётся из MediaElementSource/AnalyserNode. Для системного SpeechSynthesis звук недоступен Web Audio, поэтому выдуманный спектр не рисуется.

Подготовлены **48 653 MP3** одним нейросетевым болгарским голосом Piper bg_BG-dimitar-medium. Данные исходного голоса — CC0; тексты сохраняют свои лицензии. Это синтетические записи, не корпус дикторов-носителей. `public/audio/ATTRIBUTION.json` содержит происхождение текстов, `index.json` — сопоставление. Дополнительные фразы локальный сервер создаёт по запросу и сохраняет атомарно. Движок и модель уже подготовлены в рабочем каталоге; пользователю не предлагается устанавливать системные голоса.

Vite/preview запускают сервер на loopback автоматически и переиспользуют работающий экземпляр. Статический хостинг содержит готовые MP3, но для новых фраз потребует отдельного TTS endpoint. Кэширование уроков, диалогов и выбранных форм выполняется через единый механизм; отсутствующую форму можно сгенерировать и сохранить.

## Содержание

**16 658 словарных записей**, 16 046 исходных словоформ, 1 553 указания ударения. **17 819 уникальных переводных контекстов** (прямые Tatoeba, верифицированные цепочки через общее предложение, Викисловарь, FLORES-200 и профессиональные реплики).

Сопоставление по засвидетельствованным словоформам даёт 5 737 ссылок слово–контекст. **626 слов** имеют 3–12 контекстов и помечены как активный словарь; есть соответствующий фильтр. Остальные статьи остаются справочными. Морфологическое совпадение не заменяет разрешение омонимии; длина предложения обозначает структурную сложность, а не проверенный CEFR.

**295 глаголов**, включая 13 возвратных. 294 полные исходные таблицы импортированы из английского Викисловаря через Kaikki; одна прежняя авторская парадигма сохранена. Импорт требует все 18 личных форм трёх простых времён и четыре родо-числовые формы аористного причастия. Недостающие основы не угадываются. Составные времена образуются по грамматическим правилам. Для возвратных форм отдельно обработана позиция се. Есть источник, вид и видовые соответствия при наличии, поиск, сравнение времён, выбор рода, отрицания и вопроса, упражнения и доступные контексты из корпуса. Всего 61 328 различных строк парадигм; это не число самостоятельных предложений.

Сохранены и расширены **44 грамматические темы / 1 029 качественных интерактивных заданий** (выбор формы, ввод окончания, составление предложений, исправление ошибок, перевод RU→BG, времена, артикли, клитики). Помимо них доступны задания по выбранной парадигме. **409 полноценных диалогов / 1 742 реплики**, включая новые разговорные и технические сценарии A1–B2 с озвучиванием, точным русским переводом и контрольными вопросами.

Реализована **Лаборатория аудирования (`src/ListeningLab.tsx`)** с **525 разнообразными заданиями**:
- Короткие фразы, диалоги на слух, объявления по вокзалу, числа, цены, время, платформы, железнодорожные переговоры машинистов BDZ с дежурным по станции/диспечером и монологи.
- Регулируемая скорость воспроизведения (0.75x, 0.85x, 1.0x, 1.1x), повтор отдельных фрагментов, мгновенная проверка, показ текста и перевода с подробным комментарием.

Реализован **Голосовой тренажёр (`src/VoiceLab.tsx`)** с **305 детальными разговорными сценариями**:
- 12 жизненных и профессиональных тематик: магазин, транспорт, работа, жильё, врач, документы, кафе, собеседование, разговор с руководителем, депо, обслуживание тормозов, отказы оборудования и безопасность.
- Распознавание речи через Web Speech API с мгновенной пословной подсветкой совпадений и расхождений, эталонным озвучиванием на регулируемой скорости, разветвлёнными репликами продолжения диалога и полноценным текстовым режимом ввода для браузеров без микрофона.

**2 082 технических термина и выражения**, включая отдельные группы общеинженерной лексики; **220 профессиональных контекстных фраз**. Русские переводы в авторском глоссарии — проверенная редакция терминологии БДЖ и НКЖИ.

**596 фотографий** с авторами, источниками и лицензиями (Wikidata/Commons). Файлы оптимизированы и сжаты.

## Обучение и сохранение

FSRS продолжает отдельно учитывать узнавание и воспроизведение. Личные сложные слова можно отметить в словаре и тренировать отдельно. Ошибочные задания сохраняются с содержимым, повторяются напрямую и удаляются из списка после правильного ответа. Ошибка в старой попытке не перекрывает более поздний правильный ответ при адаптации.

Дневной маршрут учитывает слабые навыки, добавляет до трёх конкретных ошибок и два задания на соседнем уровне при достаточной выборке.

## Проверка и ограничения

Проходят **42 автоматических теста**: все сценарии, миграция и резервные копии, FSRS, продолжение сессии, конкретные ошибки, сложные слова, активный словарь, возвратные формы, адаптация, аудиоиндекс, отмена загрузки/очереди, серверный резерв, запрет неподходящих голосов, скорость/громкость, уникальность офлайн-кэша и подключение реального Web Audio. Успешно выполняются `npm test`, `npm run content:check`, `npx tsc --noEmit` и `npm run build`.

Цели по масштабированию интерактивных учебных разделов полностью достигнуты:
- Аудирование: **525 упражнений** (норматив ≥ 500)
- Голосовой режим: **305 ситуаций** (норматив ≥ 300)
- Грамматическая лаборатория: **1 029 заданий** (норматив ≥ 1 000)
- Разговорная мастерская: **409 диалогов** (норматив ≥ 400)
- Railway Academy: **2 082 термина** (норматив ≥ 2 000)
